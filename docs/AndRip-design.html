Design foundations

Primary #006B5EContainer #E8F0EBError #9D392D

Compose uses Material 3 typography and the teal/mint brand palette in both light and dark mode. The generated logo is used in the launcher and the app headers. Screen padding 16dp; spacing 8/12/16/24dp; rounded media cards; controls at least 48dp. Dark mode follows the device.

Stable item keys, scrolling quality controls, visible status text, and a bottom media action keep the interface usable on narrow screens. Native player controls provide seeking and accessible transport actions.

Interaction contract

Discover: show the page title, source host, format and readable file name. Never put signed queries in the media list.

Preview: show buffering, playback errors and a native scrubber. Pause when the app leaves the foreground; release the player on close.

Queue: exact source + quality deduplication; pause/resume; separate active, saved and attention filters. 401/403 recovery points to the source page.

Figma: Figma skills were installed, but no Figma execution or file-creation tool was available in this session. This local specification guides the implemented Compose screens; no Figma file was created.

Illustrative content only. This prototype does not make network requests or download media. Device playback and touch behavior require an Android smoke test.
